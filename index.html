Descripción general

Perfil profesional

1.1 Características

  • Full stack: interfaces con HTML, CSS, JavaScript y Vue; servidor con Java y Spring Boot.
  • Base de sistemas del Grado Medio de SMX: Linux, redes locales y hardware.
  • Entornos reproducibles con Docker y control de versiones con Git.
  • Código documentado: commits claros, README y ramas ordenadas.
  • Castellano y catalán nativos; inglés intermedio.

1.2 Aplicaciones

Dónde puedo aportar en un equipo:

  • Desarrollo de aplicaciones web completas (frontend y backend).
  • Backend con Java, Spring Boot y bases de datos SQL.
  • Frontend con HTML, CSS, JavaScript y Vue.
  • Despliegue y mantenimiento de entornos con Docker y Linux.

1.3 Descripción

Estudio segundo curso del CFGS de Desarrollo de Aplicaciones Web en el Institut Thos i Codina y estoy realizando las prácticas en empresa. Llegué a la programación desde el Grado Medio de Sistemas Microinformáticos y Redes, así que entiendo lo que hay debajo de una aplicación: el sistema operativo, la red y el despliegue, no solo el código.

Me interesan especialmente el backend con Java y Spring Boot, el despliegue con contenedores y las interfaces con Vue. Al terminar el ciclo quiero seguir creciendo como desarrollador junior dentro de un equipo.
