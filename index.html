01 · Perfil

Del hardware y las redes al desarrollo full stack

Soy estudiante de segundo curso del CFGS de Desarrollo de Aplicaciones Web en el Institut Thos i Codina. Llegué a la programación desde el Grado Medio de Sistemas Microinformáticos y Redes, así que entiendo lo que hay debajo de una aplicación: el sistema operativo, la red y el despliegue, no solo el código.

Me siento cómodo trabajando en todo el recorrido de una aplicación web: maquetar interfaces semánticas y responsive, programar la lógica en Java o JavaScript, modelar la base de datos y dejarlo todo funcionando en contenedores Docker, versionado con Git y documentado.

Me interesan especialmente el backend con Java y Spring Boot, el despliegue con contenedores y las interfaces bien construidas con Vue. Busco una empresa donde realizar las prácticas del ciclo dentro de un equipo de desarrollo real, aprender de revisiones de código y asumir tareas con responsabilidad.
